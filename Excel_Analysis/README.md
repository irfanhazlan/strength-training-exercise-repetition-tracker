# Excel Analysis

This folder contains the Excel files used to analyse the performance of the wearable strength training exercise repetition tracker.

The spreadsheets were used to organise experimental data, calculate repetition counting errors, summarise device accuracy, and prepare CSV data for MATLAB plotting.

## Files

| File | Description |
|---|---|
| `device_testing_results.xlsx` | Spreadsheet containing the repetition counting results, error calculations, summary statistics, frequency table and accuracy analysis for the strength training exercises |
| `IMU_waveforms_for_MATLAB.xlsx` | Spreadsheet containing IMU waveform data used to prepare data for MATLAB signal processing plots |
| `bicep_curl_data.csv` | CSV file exported from the waveform spreadsheet and used by the MATLAB scripts |
